### 📌 Project Overview
This is the second version of the BiteBox website.  
It expands the basic landing page by adding more sections such as Our Story, Chef’s Message, Contact Information, and Customer Notice using pure HTML.

---

### ✨ Features
- Restaurant branding with highlighted title
- Welcome section
- About BiteBox
- Our Story
- Chef’s Message
- Today’s Featured Dishes
- Special Offer section
- Contact Information
- Customer Notice
- Opening Hours
- Copyright footer

---

### 🛠️ Skills Demonstrated
- HTML5 structure
- Semantic headings and paragraphs
- Text formatting tags (`strong`, `em`, `mark`, `sup`)
- Horizontal rules and clean section layout

---

### 🚀 How to Run
1. Open the repository
2. Open `enhancement.html` in any web browser
